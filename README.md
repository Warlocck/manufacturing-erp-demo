# Manufacturing ERP Demo

Web-based manufacturing and inventory management system developed with Java, Spring Boot, React, TypeScript and PostgreSQL.

## Features

- Customer management
- Production parts management
- Inventory management
- Inventory filtering by status and customer
- Search by part code or name
- Material and weight information
- Inventory reports
- PDF generation
- REST API integration
- Mock data mode
- OpenAPI / Swagger documentation
- Global exception handling
